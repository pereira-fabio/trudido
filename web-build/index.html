This container serves a prebuilt Flutter web bundle; it does not compile one, because doing that needs several gigabytes of disk that a NAS is usually better off keeping.

Get the bundle from the Analyze workflow in GitHub Actions → the finished run → the web-app artifact. Then:

cd /opt/trudido
unzip -o ~/Downloads/web-app.zip -d web-build
docker compose up -d --build web

The sync API is unaffected and is running normally at /api/v1/.
